# React Pokémon Viewer

**Browse Pokémon and inspect their stats, powered by the public [PokéAPI](https://pokeapi.co/).**

## Features

- Full Pokémon list fetched from PokéAPI
- Click any Pokémon to load its card: image, type and battle stats
- Async data fetching with `async/await` and error handling
- Reusable Button and Card components styled with CSS Modules

## Tech stack

React 18 · Vite 5 · Sass · PokéAPI

## Run locally

```bash
git clone https://github.com/AnastaCodes/ReactPokemonViewer.git
cd ReactPokemonViewer
npm install
npm run dev
```
